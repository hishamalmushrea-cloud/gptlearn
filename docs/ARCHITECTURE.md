# ARCHITECTURE — البنية (ويب PWA)

```
index.html          الهيكل + تحميل البيانات (data قبل المنطق)
css/style.css       نظام تصميم RTL موحد
js/engine.js        SRS بأربعة تقييمات + تقييم التدريب + عزل المستورد (يُختبر في Node)
js/app.js           النواة: راوتر hash، تخزين، عرض عبارات/جداول، صوت، بحث، تقدم/مفضلة، نسخ احتياطي كامل
js/views.js         المواقف/الثقافة/الأساسيات/الأرقام/البنك/المقارنة/اختبار المستوى/الخطة
js/trainer.js       التدريب التفاعلي + إعادة تمثيل الحوارات
js/cards.js         بطاقات ليتنر حقيقية + اختبار
js/extras.js        نجاة، قصص، أخطائي، تقدم، كتابة/استماع باللغتين، ماذا أتعلم اليوم
data/**             المحتوى (فصول/حوارات/قصص/ثقافة/تحليلات/مدربون/نجاة)
```

## المبادئ (مطابقة §49–50 بتكيف الويب)
- **فصل المحتوى عن حالة المستخدم**: المحتوى JS للقراءة فقط؛ التقدم في localStorage بمعرفات ثابتة (`gl_learned/gl_favs/gl_leitner/gl_activity/gl_mistakes`) — تحديث المحتوى لا يمس التقدم أبدًا.
- **قاعدة موحدة في الذاكرة**: `window.DB` + دوال تجميع (allPhrases/bankSorted) — أي عنصر جديد يظهر تلقائيًا في البحث/البنك/البطاقات.
- **SRS قابل للاستبدال**: منطق معزول بفواصل موثقة (1/2/4/8/16 يومًا).
- **تجريد الصوت**: `speak(text, code, rate)` نقطة وحيدة — اليوم TTS الجهاز؛ مستقبلًا ملفات مسجلة بتغيير التنفيذ فقط.
- **إضافة لغة**: نفس مخطط العبارة بحقول لغة جديدة — الواجهات محايدة.

## الأوفلاين
`sw.js` كاش مسبق كامل + network-first بfallback كاش؛ `manifest.json` تثبيت standalone؛ لا طلبات شبكة في أي وظيفة تعلم.

## الاختبارات
`validate.mjs` (سلامة بيانات) + جن jsdom خارجي يغطي كل المسارات والتدفقات.
