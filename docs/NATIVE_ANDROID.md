# الأندرويد الأصلي (Compose)

المسار: `android/`

طبقات:
- `ui/` Compose فقط — بلا منطق عمل داخل الشاشات أكثر من الربط
- `domain/` نماذج + LearningEngine + بحث ضبابي
- `data/SeedContent` حزمة محتوى أصلية
- `data/UserStore` DataStore (تقدم منفصل للغتين)
- `audio/TtsPlayer` تجريد صوت الجهاز

ميزات أُضيفت لأنها تحسّن الإتقان ولم تُذكر حرفيًا:
1. صندوق «نسيت أقولها» — التقاط فجوات المتعلم فورًا أوفلاين.
2. Shadowing منظّم بسرعتين دون نسبة وهمية.
3. مدرب الحروف التركية I/ı vs İ/i.
4. جمل إنقاذ عند انقطاع اللفظ.
5. توازن ازدواج بنسبة منزلقة + توصية المحرك.
6. إخفاء العربية + وضع تركيز.
7. تصدير تقدم نصي محلي.

ما لا ندّعيه: نموذج تعرّف كلام على الجهاز، شهادات رسمية، آلاف التسجيلات البشرية في هذا الإصدار.
