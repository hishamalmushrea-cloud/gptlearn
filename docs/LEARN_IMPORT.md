# مقارنة `hishamalmushrea-cloud/learn` مع سوق اللغة (gptlearn)

مصدر المراجعة: استنساخ كامل لـ [learn](https://github.com/hishamalmushrea-cloud/learn.git) بتاريخ هذه الجلسة.

## ما هو learn؟

تطبيق **IndoLearn** أندرويد أصلي (Compose + Room + Hilt) لتعليم الإندونيسية والتركية، مع:

- 55 درسًا، ~268 مفردة، ~404 عبارة يومية، 57 سيناريو (معظمها تركي مستورد)
- موسوعة Markdown: 28 ملف ID + 6 TR (~10 800 سطر)
- محرك SM-2 مختبَر + Daily Coach + فاحصات Python
- مسار جانبي **رياضة/ريادة** (`riyada_data.json` ~169 KB) — خطة تاجر 3 سنوات للسوق السعودي، **ليست لغة**

التدقيق الداخلي في `AUDIT.md` صادق جدًا: كان فيه دروس تعرض محتوى غيرها، بذر يمسح التقدم، SRS اسم بلا منطق، ثم أُصلح كثير منه.

## ماذا لدينا أصلًا ولا ننسخه أعمى؟

| عندنا (gptlearn) | عندهم (learn) |
|---|---|
| PWA بمئات/ألف عبارة بيع موثّقة + مواقف + ثقافة سوق | عبارات أقل عمقًا في البيع لكن موسوعة نحوية أوسع |
| عربي فصحى تعليمي | كثير من الشروح **مصرية عامية** («بتروح فين؟») |
| Compose نواة جديدة + DataStore | Room كامل + Hilt + 27 شاشة |
| لا ندّعي بناء APK هنا | CI بنى APK في Actions |

**لا ننقل:** Room كما هو (بذر REPLACE، `fallbackToDestructiveMigration`، حقول `lessonId` الملتبسة)، Lottie من الإنترنت، أرقام تقدّم ثابتة كاذبة، `riyada` كامل داخل مسار اللغة دون فصل، تكرار المفردات.

## ما يستحق النقل (نُفِّذ / لم يُنفَّذ)

| البند | القرار | الحالة |
|---|---|---|
| موسوعة `library/id` + `library/tr` | نعم — مرجع أوفلاين بطبقات | ✅ نُسخت إلى `android/.../assets/library` و`docs/library` |
| SM-2 + ease + إعادة 10 دقائق + FORGOTTEN | نعم أفضل من صناديق بسيطة | ✅ `domain/Sm2.kt` |
| Daily Coach: منع درس جديد عند دين مراجعة | نعم مبدأ تعليمي قوي | ✅ `DailyCoach` |
| AnswerEvaluator بلا نجاح substring زائف | نعم | ✅ |
| أسئلة السجل: berkata→bilang، bagaimana→gimana | نعم فجوة عندنا | جزئيًا في العيّنة + الموسوعة |
| تحذيرات تركية (moruk / lan) | نعم في ملفات TR | ✅ عبر المكتبة |
| 49 حوار تركي في الموسوعة | نعم كمرجع لا صفوف مخترعة الترجمة | ✅ ملفات `bank_diyaloglar.md` |
| أدوات `validate_*.py` | نعم لاحقًا على حزم JSON | ⏳ نقتبس الفكرة لا كل السكربتات المرتبطة بـ Room |
| خطة رياضة 3 سنوات | **مسار منفصل** «التاجر» إن طُلب — لا تخلط مع CEFR | ❌ لم تُدمج في نواة اللغة |
| Gradle Wrapper | مفيد | لديهم wrapper؛ نضيفه عند توفر الشبكة |

## دروس هندسية نأخذها ولا نكرر أخطاءهم

1. **لا تخلط «جارٍ التحميل» مع «لا بيانات»** — دوامة أبدية.  
2. **البذر ذري + حارس اكتمال لكل الجداول** لا `count > 0`.  
3. **العنوان يجب أن يطابق شواهد لغوية في جسم الدرس.**  
4. **لا تترجم حوارًا بلا سطر ترجمة في المصدر.**  
5. **اختبارات تطفر** (غيّر ثابتًا وتأكد أن الاختبار يسقط).  
6. المكتبة تتبع اللغة: متعلم التركية لا يرى مرجعًا إندونيسيًا.

## فجوات learn التي نحن أقوى فيها (لا نتراجع)

- عمق **لغة البيع** والمساومة وجذب الزبون بالعربية الفصحى + متى/لماذا.  
- بنك أولوية p1–p5 ومقارنة ثلاثية.  
- خصوصية أوفلاين بلا شبكة في الترحيب.  
- صندوق «نسيت أقولها» ومدرب الحروف I/ı.

## الخطوة التالية المقترحة

استخراج صفوف منتظمة من الموسوعة (جداول فقط) إلى `SeedContent` بعد فلتر الفصحى، مع وسم `ar_register=msa|egyptian` للصفوف المصرية بدل إعادة كتابتها صامتة.
