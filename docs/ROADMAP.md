# ROADMAP

> الأولوية حسب أثر التعلم الفعلي.

## قرار المنصة (مُغلق نهائيًا — 2026-09)
**أندرويد Native (Compose) هو المنتج الوحيد.** لا WebView ولا PWA منتَج، ولا منهجان متوازيان. `data/**` مصدر تأليف العبارات ويولّد منه `tools/gen_android_content.mjs` محتوى التطبيق (يفرض CI التزامن). ملفات الويب معاينة داخلية فقط.

## مراحل منصات-محايدة
- **R1** فصل تقدم اللغتين (phrase × language) + لوحة «إندونيسي A2 51% / تركي A1 24%».
- **R2** هيكل CEFR خفيف: وسم المحتوى بمستويات تقديرية + مسارات.
- **R3** محرك «ماذا أتعلم الآن؟» (ضعف/استحقاق/هدف يومي).
- **R4** تمارين كتابة (ترتيب كلمات، إكمال، كتابة بتصحيح ضبابي).
- **R5** مدرب أفعال تفاعلي + أزواج نطق صغرى.
- **R6** مواقف إضافية: مطار حوار كامل، بنك، شرطة، مقابلة عمل، جامعة، سفارة، إيجار.
- **R7** قصص أكثر (12 قصة A1→B1).
- **R8** حزم محتوى JSON مُصدَّرة (schemaVersion) + سجل كلمات كامل.
- **R9** حقول جودة المحتوى (status/region/version).

## المسار الأصلي (اُختير)
✅ منجز: Compose M3 بشاشات كاملة، DataStore للتقدم، SRS Native (Leitner) + SM‑2، TTS مهيأ، مكتبة Markdown أصولية، اختبارات وحدات JVM لمنطق المجال، CI يبني APK وينشره بإصدار.
التالي هنا: **N1** Room بمخطط §49 بدل سلاسل DataStore النصية للمراجعة — **N2** ترحيل نطاق المولّد ليشمل القاموس/الحوارات/القصص (أو إعلان Kotlin مصدرًا وحيدًا لها رسميًا) — **N3** AudioRepository (تسجيلات بشرية + TTS احتياط) — **N4** Gradle Wrapper — **N5** كلين أرشيتكتشر متعدد الوحدات عندما يكبر الكود فعلًا. أي كود غير مُتحقق من بنائه يُعلَّم بوضوح.
