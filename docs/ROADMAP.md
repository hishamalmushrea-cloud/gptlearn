# ROADMAP

> الأولوية حسب أثر التعلم الفعلي.

## القرار المعلق الأول: المنصة
1. **الاستمرار PWA** — كل الجهد للمحتوى والمحرك (التثبيت كتطبيق ممكن من المتصفح).
2. **بدء أندرويد أصلي** إلى جانب الويب (Gradle متعدد الوحدات + استيراد نفس البيانات) — لا يمكن التحقق من البناء في البيئة الحالية (بلا Android SDK)؛ يُقدَّم أقوى تجريد وفق §81.
3. **ويب الآن + أندرويد عند توفر بيئة بناء** (موصى به).

## مراحل منصات-محايدة
- **R1** فصل تقدم اللغتين (phrase × language) + لوحة «إندونيسي A2 51% / تركي A1 24%».
- **R2** هيكل CEFR خفيف: وسم المحتوى بمستويات تقديرية + مسارات.
- **R3** محرك «ماذا أتعلم الآن؟» (ضعف/استحقاق/هدف يومي).
- **R4** تمارين كتابة (ترتيب كلمات، إكمال، كتابة بتصحيح ضبابي).
- **R5** مدرب أفعال تفاعلي + أزواج نطق صغرى.
- **R6** مواقف إضافية: مطار حوار كامل، بنك، شرطة، مقابلة عمل، جامعة، سفارة، إيجار.
- **R7** قصص أكثر (12 قصة A1→B1).
- **R8** حزم محتوى JSON مُصدَّرة (schemaVersion) + سجل كلمات كامل.
- **R9** حقول جودة المحتوى (status/region/version).

## إن اختير أندرويد الأصلي
P0 هيكل Gradle (app/core/feature) + Compose M3 — P1 Room بمخطط §49 + مستورد من نفس البيانات — P2 نقل منطق SRS/Mistakes إلى Kotlin — P3 AudioRepository (ملفات + TTS احتياط). أي كود غير مُتحقق من بنائه يُعلَّم بوضوح.
