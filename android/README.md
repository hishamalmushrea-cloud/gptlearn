# سوق اللغة — غلاف أندرويد للأوفلاين

التطبيق مجاني بالكامل: بلا اشتراك وبلا إعلانات وبلا مشتريات.

## المسار التقني الواحد

الأكاديمية الحقيقية هي الـ **PWA** في جذر المستودع (المحتوى + المحرك).
تطبيق أندرويد غلاف `WebView` يحمّل `file:///android_asset/index.html`.

عند البناء تُنسخ ملفات الويب إلى `assets/` بمهمة Gradle `copyWebAssets` (وأيضًا في CI).

مكتبة Markdown في `assets/library/` تبقى مرجعًا أوفلاين؛ شاشة Compose القديمة لم تعد نقطة الدخول.

## البناء

افتح `android/` في Android Studio أو:

```
gradle -p android assembleDebug
```

`minSdk 24` · لا صلاحية إنترنت.

## لماذا ليس Compose هو الواجهة؟

نواة Compose كانت عيّنة صغيرة منفصلة عن 1300 عبارة ويب. الإبقاء على منصتين يعني محتوى مزدوجًا يتأخر. الغلاف يعطي المستخدم نفس المنهج كاملًا أوفلاين.
