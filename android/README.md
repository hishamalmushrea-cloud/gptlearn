# سوق اللغة — تطبيق أندرويد Native (المنتج الوحيد)

هذا المجلد هو المنتج: **تطبيق أندرويد فقط بواجهة Jetpack Compose**.

- لا WebView.
- لا `index.html` داخل APK.
- لا نسخ لملفات الويب أثناء البناء.
- لا صلاحية إنترنت في الـ Manifest.
- المحتوى الأساسي المحلي موجود في `SeedContent.kt` ويُحفظ تقدم المستخدم عبر DataStore.
- النطق يستخدم Android TextToSpeech مع نص عربي مساعد.
- المكتبة المرجعية Markdown داخل `app/src/main/assets/library` وتُقرأ Native من `LibraryScreen`.

## البناء

افتح `android/` في Android Studio أو شغّل:

```bash
gradle -p android assembleDebug
```

إعدادات التطبيق الحالية:

```text
minSdk 24
compileSdk 34
targetSdk 34
Kotlin 1.9.24
Java 17
```

> ملاحظة: لا يوجد Gradle Wrapper حاليًا؛ يُنصح بإضافته في الخطوة التالية لضمان قابلية البناء على كل جهاز وداخل CI.

## مصدر المحتوى

- **العبارات (1000 ثنائية اللغة):** مصدرها `data/**` في الجذر وتتولّد آليًا عبر `node ../tools/gen_android_content.mjs` إلى `data/FullContent.kt` — لا تعديل يدويًا، وCI يفرض التزامن. العبارات المستوردة أحادية اللغة لا تدخل التطبيق.
- **المجموعات الباقية** (قاموس 160 كلمة، 33 حوارًا، 29 قاعدة، 8 قصص، 16 فعلًا، 30 تحليلًا، 8 سيناريوهات تدريب) نُقلت كاملةً إلى Kotlin وتُحرَّر هنا مباشرة.
- `index.html`/`js/`/`css/` في الجذر استوديو معاينة للمؤلفين فقط ولا تدخل البناء.

## الاختبارات

```bash
gradle -p android testDebugUnitTest   # اختبارات منطق المجال (SM-2/التقييم/المدرب/البحث)
```
- 29 قاعدة.
- 33 حوارًا كاملًا.
- 8 قصص.
- 14 ملاحظة ثقافية.
- 16 فعلًا.

وتوجد أيضًا دروس قصيرة وسيناريوهات واختبارات Native مخصصة لواجهة التدريب. الخطوة التالية ليست نسخ محتوى الويب إلى APK، بل تحسين تنظيمه داخل فصول Native، وربط كل عنصر بمسار الدرس والتقدم والبطاقات والاختبارات.
