# سوق اللغة — تطبيق أندرويد Native

هذا المجلد هو المنتج المستهدف: **تطبيق أندرويد فقط بواجهة Jetpack Compose**.

- لا WebView.
- لا `index.html` داخل APK.
- لا نسخ لملفات الويب أثناء البناء.
- لا صلاحية إنترنت في الـ Manifest.
- المحتوى الأساسي المحلي موجود في `SeedContent.kt` ويُحفظ تقدم المستخدم عبر DataStore.
- النطق يستخدم Android TextToSpeech مع نص عربي مساعد.
- المكتبة المرجعية Markdown داخل `app/src/main/assets/library` وتُقرأ Native من `LibraryScreen`.

## البناء

افتح `android/` في Android Studio أو شغّل:

```bash
gradle -p android assembleDebug
```

إعدادات التطبيق الحالية:

```text
minSdk 24
compileSdk 34
targetSdk 34
Kotlin 1.9.24
Java 17
```

> ملاحظة: لا يوجد Gradle Wrapper حاليًا؛ يُنصح بإضافته في الخطوة التالية لضمان قابلية البناء على كل جهاز وداخل CI.

## مصدر المحتوى

تم إيقاف مسار الويب بالنسبة إلى APK. ملفات `data/` و`js/` الموجودة في جذر المستودع هي بقايا PWA/مصدر تاريخي وليست جزءًا من بناء أندرويد الحالي. لا تُضاف ميزة جديدة إليها؛ أضف المحتوى إلى نماذج Kotlin ومصدر المحتوى Native، ثم أضف اختبارًا له.

تم نقل المحتوى الأساسي إلى Native Kotlin:

- 1000 عبارة ثنائية اللغة.
- 160 كلمة قاموس.
- 29 قاعدة.
- 33 حوارًا كاملًا.
- 8 قصص.
- 14 ملاحظة ثقافية.
- 16 فعلًا.

وتوجد أيضًا دروس قصيرة وسيناريوهات واختبارات Native مخصصة لواجهة التدريب. الخطوة التالية ليست نسخ محتوى الويب إلى APK، بل تحسين تنظيمه داخل فصول Native، وربط كل عنصر بمسار الدرس والتقدم والبطاقات والاختبارات.
