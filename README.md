# 🛍️ سوق اللغة — نظام تدريب متكامل للإندونيسية والتركية (للعرب)

تطبيق ويب **يعمل دون إنترنت بالكامل (Offline-first PWA)** لتعليم العربية-المتحدثين الإندونيسية 🇮🇩 والتركية 🇹🇷 — بتركيز استثنائي على **البيع والشراء والتعامل مع الزبائن**: من لحظة دخول الزبون حتى ما بعد البيع.

> الفلسفة: لا نعلّم «كيف أترجم الجملة؟» بل نوصل المتعلم إلى:
> **«أنا أعرف ماذا أقول، وكيف أقوله، ولمن أقوله، ومتى أقوله، وكيف أقوله بطبيعية.»**

---

## 🚀 التشغيل

- **أسهل طريقة:** افتح `index.html` مباشرة في المتصفح — يعمل فورًا بلا خادم وبلا إنترنت.
- **كموقع (يفعّل التثبيت كتطبيق PWA):** شغّل أي خادم ملفات ثابت:
  ```bash
  python3 -m http.server 8080
  # ثم افتح http://localhost:8080
  ```
- التقدم كله (المحفوظ، المفضلة، صناديق الحفظ) يُخزَّن في جهازك `localStorage`، ومعه زر تصدير/استيراد نسخة احتياطية JSON.

## 🗺️ ماذا يحتوي التطبيق؟

### 0) 🎓 المنهج العام (الأكاديمية) — مسار تعلم اللغة الكامل خارج المحل
- **6 فصول أكاديمية:** الضمائر والتعريف بالنفس · أدوات الأسئلة الذهبية (جدول كامل) · الأفعال الذهبية العشرون + جدول تصريف الفعل التركي · الوقت والأيام والساعة · الصفات والمشاعر والمقارنة · المفردات الموضوعية الكبرى (8 عوالم: العائلة، الطعام، المواصلات، الصحة، البيت، الطقس، الملابس، العمل).
- **8 حوارات حياة يومية كاملة:** مطعم إندونيسي · تاكسي تركي · فندق · صيدلية · السؤال عن الطريق · تعارف ودعوة شاي · مكالمة هاتفية · دردشة الجيران («Mau ke mana?» و«Udah makan?»).
- **🎯 اختبار تحديد المستوى:** 12 سؤالًا متدرجة الصعوبة من بنك الجمل، والنتيجة خريطة بداية مخصصة (مبتدئ/ما بعد المبتدئ/متوسط/متقدم) بروابط مباشرة لما يناسبك.
- **🗓️ خطة 30 يومًا:** برنامج يومي 20–30 دقيقة (أسبوع أساس ← أسبوع بناء جمل ← أسبوع دخول السوق ← أسبوع مساومة واحتراف) بروابط لكل يوم.

### 1) 🛍️ قسم البيع والشراء والتعامل مع الزبائن (القسم الأهم — 15 فصلًا)
| الفصل | يغطي |
|---|---|
| 🧲 جذب انتباه الزبون | ما يقوله البائع **فعلًا** — لا ترجمة حرفية لـ«تعال شوف» + جدول الترجمات الحرفية الفاشلة |
| 👋 الترحيب بالزبائن | مصفوفة ترحيب لكل نوع زبون (واحد/جماعة/دائم/أول مرة/رسمي/مستعجل/متفرج/كبير سن) + بروتوكول Hoş geldiniz/Kolay gelsin |
| 🗣️ المخاطبة حسب الجنس والعمر | قاموسا الكنيات الكاملان (kak/mbak/mas/Bu/Pak… وabi/abla/teyze/hanım/hocam…) + متى **لا** يتغير شيء |
| 📦 عرض المنتجات | 40 عبارة وصف منتج + جدول الألوان والمقاسات والمواد |
| 🔎 معرفة احتياج الزبون | أسئلة الاكتشاف الاحترافية (لمن؟ ميزانية؟ لون؟ استخدام؟) |
| 🤝 الإقناع بدون إزعاج | + **دليل «متى تتوقف عن البيع فورًا»** (إشارات الرفض الثلاث وقاعدة 3×3) |
| 💰 الأسعار | قول السعر + قاموس لغة الأسعار بين الروبية والليرة |
| 🤝 المساومة | سلّم التنازل الاحترافي + المساومة بالآلة الحاسبة + أشهر جمل التفاوض |
| 🧾 إتمام البيع | الكيس، الفيشت، QRIS/البطاقة، الباقي، الضمان، التوصيل، التوديع |
| 🙅 التعامل مع رفض الزبون | مصفوفة الرفض: ماذا قال → المعنى الحقيقي → ردك الطبيعي |
| 😤 الزبون الغاضب والشكاوى | معادلة الشكوى الذهبية + قاعدة الدماء الأربع + الاستبدال/الاسترجاع/الإصلاح |
| 🤔 الزبون المتردد | إزالة التردد بلا ضغط |
| 🌍 الزبون الأجنبي | جمل قصيرة، أرقام مكتوبة، تأكد الفهم |
| 📦 الجملة والتجزئة | قاموس جملة كامل + التفاوض مع الموردين + الدفع الآجل والحجز |
| 📱 الهاتف والواتساب | 20 قالب رسالة حية (سعر، متابعة، تأكيد، دفع، شحن، متابعة ما بعد البيع) |

كل عبارة موثّقة: **الترجمة الطبيعية + النطق بالعربية + مستوى الرسمية (رسمي/محايد/عادي/عفوي جدًا) + متى تُستخدم + لماذا هي طبيعية + الترجمة الحرفية عند الحاجة + بدائل.**

### 2) 🎬 المواقف الكاملة (18 حوارًا حيًا)
منهجية كل موقف: **الموقف ← الحوار الكامل (مع ملاحظة «لماذا قلنا هذا» تحت كل سطر) ← الكلمات المهمة ← القاعدة التي تحتاجها هنا فقط ← لماذا استخدمنا هذه العبارات ← نسخة أكثر رسمية وأكثر عفوية ← إعادة تمثيل الحوار بدور البائع أو الزبون بأي من اللغتين.**

بيع وسوق (10): محل ملابس إندونيسي، مساومة سوق جاكرتا، مساومة البازار التركي، زبون مستعجل، شكوى واستبدال (تركي)، خطأ طلب واسترجاع (إندونيسي)، تفاوض جملة مع مورد، زبون أجنبي، زبونة مترددة، طلب واتساب كامل.
حياة يومية (8): مطعم، تاكسي، فندق، صيدلية، اتجاهات، تعارف وشاي، مكالمة هاتفية، دردشة الجيران.

### 3) ⭐ بنك الجمل الجاهزة
كل عبارات التطبيق (422 جملة: البيع + الأكاديمية + الأساسيات) تدخل البنك تلقائيًا وتُرتَّب بالأولوية (p1–p5) في مستويات: **أهم 50 ← 100 ← 250 ← 500 ← الكل** — والبنية قابلة للتوسع إلى 1000+ بإضافة ملفات بيانات فقط.

### 4) 🔁 المقارنة الثلاثية
30 تحليلًا عميقًا: «كيف أقولها كعربي؟» → ما يقوله الإندونيسي/التركي فعلًا + الترجمة الحرفية + النطق + الرسمية + متى تُستخدم + **هل تبدو طبيعية؟** + **البديل الأفضل** + ملاحظة خبير.

### 5) 🎭 التدريب التفاعلي
- 8 سيناريوهات مكتوبة يدويًا: **أنا البائع** أو **أنا الزبون**، بالإندونيسية أو التركية.
- وإعادة تمثيل تلقائية لأي حوار من المواقف بدورك ولغتك المختارة.
- تقييم **صادق** (ممتاز/جيد/يحتاج تحسين) بمطابقة ضبابية على إجابات المتحدث الأصلي + الكلمات المفتاحية — بلا درجات وهمية، مع الإجابة النموذجية وتلميح ومقارنة سبب الاستخدام.

### 6) 🃏 البطاقات والاختبار
- حفظ بتكرار متباعد (صناديق ليتنر 1–5 بمواعيد مراجعة).
- اختبار اختيار من متعدد يُبنى من بياناتك.
- مجموعات: أهم 50/100/250/500/الكل/لم أنهها/المفضلة/فصل محدد.

### 7) 🔤 الأساسيات و🔢 الأرقام و💡 ثقافة السوق
- نطق كل لغة للمتحدث العربي مع «مصائد العرب».
- الأرقام و**قراءة الأسعار كما يقرؤها الباعة فعلًا** (سر «seratus = مئة ألف»، و«on lira elli»).
- 14 مقال خبرة ميدانية: بروتوكول Hoş geldiniz، أين تحرج نفسك بالمساومة، اليد اليمنى، jam karet «الساعة المطاطية»، QRIS والأقساط، أخطاء العرب الشائعة…

## 🧱 البنية التقالية (للتوسعة إلى آلاف العبارات)

```
index.html            الواجهة (RTL عربية بالكامل)
css/style.css         التصميم
js/app.js             النواة: راوتر، تخزين، عرض العبارات، صوت، بحث، تقدم
js/views.js           المواقف/الثقافة/الأساسيات/البنك/المقارنة
js/trainer.js         محرك التدريب التفاعلي + إعادة تمثيل الحوارات
js/cards.js           البطاقات (ليتنر) + الاختبار
data/core/basics.js   الحروف والنطق + عبارات النجاة + الأرقام
data/core/academy1.js فصول الأكاديمية (ضمائر، أسئلة، أفعال، وقت، مشاعر)
data/core/academy2.js المفردات الموضوعية الكبرى (8 جداول)
data/daily/dailySituations.js حوارات الحياة اليومية (مطعم، تاكسي، فندق…)
data/sales/part1..7.js  فصول قسم البيع (عبارات + جداول + أدلة)
data/sales/situations.js حوارات المواقف الكاملة
data/sales/culture.js    مقالات ثقافة السوق
data/core/analyses.js    تحليلات المقارنة الثلاثية
data/train/trainers.js   سيناريوهات التدريب
sw.js + manifest.json + icons/   (PWA أوفلاين)
validate.mjs          فحص بيانات: node validate.mjs
```

### بنية عبارة واحدة (أضف آلافًا بنفس النمط)
```js
{id:"pri-xx", a:"العربية", i:"الإندونيسية", it:"النطق بالعربية",
 t:"التركية", tt:"النطق", lv:1..4 /*رسمي..عفوي*/, p:1..5 /*أولوية البنك*/,
 w:"متى تستخدمها", n:"لماذا طبيعية", lit:"حرفيًا عند الحاجة", alt:["بدائل"]}
```
- `p:1` = من أهم 50 جملة في البنك كله — البنك يعيد ترتيب نفسه تلقائيًا.
- موقف جديد = كائن في `situations.js` (turns + vocab + grammar + why + variants) — ويصبح فورًا قابلًا لإعادة التمثيل تدريبيًا من دون أي كود إضافي.
- سيناريو تدريب يدوي = كائن في `trainers.js` (turns بها accept + keys + model + hint + why).
- بعد أي إضافة: `node validate.mjs` للفحص، ثم حدّث رقم `CACHE` في `sw.js` لإجبار تحديث الأجهزة.

## 🧪 الاختبارات
- `node validate.mjs` — سلامة البيانات (تكرار المعرفات، الحقول الناقصة، توزيع الأولويات، الإحصاءات).
